\begin{abstract}
The square of a graph is obtained by joining every pair of vertices whose distance is at most two. Given a graph $G$, the graph square root problem asks whether there exists a graph $H$ such that $G=H^2$ and, if so, whether such a root can be constructed in polynomial time. Whilst this problem admits polynomial-time algorithms for restricted classes of root graphs, the general decision problem is NP-complete.

In this thesis, rather than studying the construction problem directly and utilizing reduction techniques to ascertain polynomial-time algorithms, we formulate the problem as an integer program based on the relationship between the adjacency matrices of a root $H$ and its square $G$. By constructing the corresponding linear relaxation, the problem can then be situated within polynomial time through the use of interior-point methods.

The seminal result for the problem is the work by \citeauthor{ross_1960_square}, who approached the problem by restricting the root graphs to trees. By analyzing the number of cliques which each vertex in the graph square is situated in, a polynomial-time algorithm was given for finding the unique tree root up to isomorphism. In contrast, our formulation provides an optimization-based approach that can be iteratively strengthened through the addition of further constraints. These constraints progressively refine the linear relaxation, enabling tree roots to be represented by integral solutions, while graphs with no possible roots are identified through fractional or infeasible solutions. Rather than relying on heuristic such as rounding, our approach exploits structural properties of the graph square and its root to obtain a deterministic solution. 
\end{abstract}

\section{Background}

In 1949, Leon Festinger proposed a novel method in the field of social psychology for analyzing relationships among a number of people present \cite{festinger_bahoken_beauguitte_2023}. Classically, this was represented using a sociogram, a visual tool that maps out the relationships between people. However, Forsyth and Katz introduced the use of a matrix to represent the sociometric pattern, with rows and columns corresponding to individuals and containing $1$s for choices and blank diagonals.
Festinger noticed that his structure, reminiscent of the adjacency matrix defined by \citeauthor{konig_1936} in \cite{konig_1936}, also had the remarkable property that the action of squaring a matrix 
\[
A_{rc}^2 = A_{1c}A_{r1} + \dots + A_{nc}A_{rn} \footnote{$A_{rc}^2$ is more naturally written as $\displaystyle \sum_{k = 1}^n A_{ck}A_{kr}$ using the commutativity of multiplication $A_{1c}A_{r1} = A_{c1}A_{1r}$, which intuitively gives the notion of paths from c to r via intermediary k}
\]
represented the number of ``two-step'' connections, which can then be used to denote ``three-step'' connections between any two people  
\[
A_{rc}^3 = A_{1c}A_{r1}^2 + \dots + A_{nc}A_{rn}^2, \footnote{$A_{rc}^3$ is more naturally written as $\displaystyle \sum_{k=1}^n A_{ck}A^2_{kr}$, which intuitively counts the number of paths from $c$ to $r$ that go through an intermediate vertex $k$, followed by any two-step path from $k$ to $r$.}
\]
such that higher steps can be easily generated. In this manner, higher powers of the adjacency matrix encode the number of walks of increasing length between pairs of individuals, allowing densely connected groups of people, known as cliques, to be identified.

In the process of improving Festinger's clique detection methods, \citeauthor{ross_1960_square} showed that complete graphs may be realized as squares of star trees by considering powers of such matrices \cite{ross_1960_square}. They introduced a structural characterization of the square of a graph in terms of clique intersections, ``multicliqual'' vertices, and so called ``neighborly'' properties, proving that a graph is the square of a tree if and only if
\begin{enumerate}[label=\roman*)]
  \item every vertex is ``neighborly'' - is not isolated and has an edge to another vertex, 
  \item no two cliques intersect in more than two vertices, and
  \item the number of clique pairs intersecting in two vertices is exactly one less than the total number of cliques. 
\end{enumerate}

Using these properties, they constructed an explicit algorithm that recovers the underlying tree for a given graph square. Their seminal paper has become the foundational reference for the study of graph squares and is universally cited in subsequent literature on the subject, and will be explored in more detail later. 

Since then, the problem of finding the square root of a graph has extended beyond sociology and is a well-studied field in both mathematics and computer-science, with direct applications in distributed computing (e.g., see \cite{peres_2023_distributed}), network design and computational biology. This is in part because many structural properties of graph roots are first established in the square case before being extended to the more general $k$-th power setting (e.g., see \cite{harary_1962_planarity}). 

Research in this area has primarily focused around an undirected graph $H$ and its square $G = H^2$ which is obtained by adding an edge between every pair of vertices whose distance in $H$ is at most two.This two-step undirected graph square has been studied extensively with much of the focus being on the complexity of the decision problem - given a specific graph square $G$ does there exist a root graph $H$ such that $H^2=G$. \citeauthor{motwani_sudan_1994_roots} showed that graph squares are NP-complete in general and hence subsequent studies in the area have restricted the decision problem in two ways, either by considering various properties on the root graph or by considering properties on the graph square. 


% In addition to these properties, there must exist a one-to-one correspondence between maximal cliques and multicliqual vertices where a vertex is called multicliqual if it belongs to at least two maximal cliques. If a multicliqual vertex $b$ belongs to exactly $k$ maximal cliques, then the clique corresponding to $b$ contains exactly $k$ multicliqual vertices. Furthermore, if two maximal cliques intersect at exactly one vertex $b$, then there exists a third maximal clique which contains $b$ and shares exactly one additional vertex with each of the original two cliques.


\section{Literature}
Focusing first on special undirected graph classes, the aforementioned work by \citeauthor{ross_1960_square} in 1960 gives an algorithm for constructing a tree root by using characterizations of the graph square. As part of this work they proved tree square roots are unique up to isomorphism. This was the first major contribution to the study of graph roots and provided fundamental structural characteristics of graph squares, laying the groundwork for later research on graph root problems and their applications \cite{ross_1960_square}. 

\citeauthor{fleischner_1974_square} in 1974 showed that as long as a graph is 2-connected its graph square will have a Hamiltonian cycle. This established a broad condition guaranteeing Hamiltonicity in graph squares which is used in many subsequent works \cite{fleischner_1974_square}. 

Lau and Corneil in 2004 provided an algorithm for constructing square roots from an interval square in polynomial time, and showed that the decision problem for finding roots of chordal graphs, roots of split graphs, and chordal roots of graphs are NP-complete \cite{lau_corneil_2004_chordal_root}. Furthermore, Lau considered the construction of square roots from a bipartite graph in linear time, and showed that the existence of cube roots in bipartite square is NP-complete \cite{lau_2006_bipartite_roots}. 

Le and Tuy in 2007 generalized tree-root results further by giving a linear time recognition of roots of block graphs \cite{le_tuy_2007_block_square}. 

Extending to the broader generalizing of graph squares, Mukhopadhyay in 1967 provided necessary and sufficient conditions for a connected graph to have a generalized square root \cite{mukhopadhyay_1967_root}, whilst Geller in 1970 likewise found necessary and sufficient conditions for a digraph to have a square root \cite{geller_1970_root}. 

In 1994 Motwani and Sudan established the complexity of the square problem for the generalized undirected case and showed that the problem of determining if a given graph has a square root is a NP-complete problem via a polynomial reduction to 3-CNF Not-All-Equal SAT \cite{motwani_sudan_1994_roots}.

Their work led to joint work by Farzad, Le, Tuy, Lau and Karimi in 2009 and 2012, in which they established a partial dichotomy theorem for the complexity of determining if a given undirected graph of girth $n$ has a square root \cite{farzad_2009_roots} which was informally completed under \cite{farzad_karimi_2012_root}. In 2013, Cochefert and others gave an algorithm for constructing a square root with minimal number of edges from undirected graphs with max degree $\leq 6$ in polynomial time and an algorithm for constructing maximal edge square roots in exponential time \cite{cochefert_et_al_2013_sparse_square_roots}. 

In recent years, Duffy provided a full classification for the undirected square of oriented graphs satisfying max degree $\leq 3$ and girth $\geq 4$ \cite{duffy_2025_oriented_root}.

The first algorithm we explore is the proof used by \citeauthor{motwani_sudan_1994_roots} in showing that the decision problem determining whether a given graph $G$ admits a square root is NP-complete in general \cite{motwani_sudan_1994_roots}. Next, we introduce the polynomial time algorithm given by \citeauthor{ross_1960_square} for constructing a tree root from a given square in detail.

Finally, we introduce additional augmentations that can be added to the linear program, the structures that bound both the square and the root, and the various methods that can be used to improve the algorithm.  

\section{Definitions and Notations}

\subsection{Complexity Theory}

Complexity theory studies the classification of computational problems and explores the amount of resources required to solve certain problems. The critical resource that is measured is running time and is standardized across various different problems by using 

\begin{definition}[Big-$O$ Notation] \label{def::big_O_notation}
  Let $f,g:\mathbb{N} \rightarrow \mathbb{R}_{\geq 0}$. The \textbf{Big-$O$ Notation} $f(n)=O(g(n))$ is written if there exist constants $c>0$ and $n_0\in\mathbb{N}$ such that for all $n\geq n_0$
  \[
  f(n)\leq c g(n). 
  \]
\end{definition}

Using this notation, we can classify algorithms based on their runtime. 

\begin{definition}[Polynomial-Time Algorithm] \label{def::polynomial_time_algorithm}
  An algorithm is said to run in \textbf{polynomial time} if there exists a constant $c \ge 0$ such that its run time on inputs of size $n$ is $O(n^c)$.
\end{definition}

Polynomial-time algorithms are important because they are generally regarded as efficient and computationally ``simple". Consequently, the class of problems that admit polynomial-time algorithms forms the basis for the complexity class $\mathbf{P}$.

\begin{definition}[Decision Problem] \label{def::decision_problem}
  A \textbf{decision problem} is a computational problem whose output is either \textbf{Yes} or \textbf{No} for every valid input instance. 
\end{definition}

\begin{definition}[Class $\mathbf{P}$] \label{def::class_p}
  The complexity class $\mathbf{P}$ consists of all decision problems that can be solved by a deterministic algorithm in polynomial time.
\end{definition}

Unfortunately many important decision problems are not known to admit such polynomial-time algorithms and hence need additional classification on their ``hardness''. For these problems, despite not have an efficient algorithm for finding a solution, a proposed solution can be verified efficiently.

\begin{definition}[Certificate] \label{def::certificate}
  Let $L$ be a decision problem. A \textbf{certificate} for an instance $x$ of $L$ is a finite string $c$ that provides evidence that $x$ is a \textbf{Yes}-instance of $L$. A certificate is said to be \textbf{polynomially verifiable} if there exists a deterministic algorithm that for given input $(x,c)$, can determine whether $c$ is a valid certificate for $x$ in time polynomial in $|x|$.
\end{definition}

\begin{definition}[Class $\mathbf{NP}$] \label{def::class_np}
  The complexity class $\mathbf{NP}$ consists of all decision problems for which every \textbf{Yes}-instance admits a certificate that is polynomially verifiable. 
\end{definition}

Since every decision problem in $\mathbf{P}$ can be solved in polynomial time, a solution can also be verified in polynomial time,
\[
\mathbf{P} \subseteq \mathbf{NP}.
\]
Whether this inclusion is strict remains one of the most important open questions in theoretical computer science - the $\mathbf{P}$ vs $\mathbf{NP}$ problem. As $\mathbf{NP}$ is a large class of decision problems, the relative difficulty of problems in $\mathbf{NP}$ is compared by using reduction. 

\begin{definition}[Polynomial-Time Reduction] \label{def::polynomial_time_reduction}
  Let $A$ and $B$ be decision problems. A \textbf{polynomial-time reduction} from $A$ to $B$, denoted $A \leq_p B$, is a polynomial-time computable function $f$ such that, for every instance $x$ of $A$,
  \[
  x \in A \Longleftrightarrow f(x) \in B.
  \]
\end{definition}

This notion of reduction allows the computational difficulty of problems to be compared. In particular, a problem is $\mathbf{NP}$-hard if every problem in $\mathbf{NP}$ can be reduced to it in polynomial time.

\begin{definition}[Class $\mathbf{NP}$-Hard] \label{def::class_np_hard}
  A decision problem $B$ is \textbf{$\mathbf{NP}$-hard} if every problem $A \in \mathbf{NP}$ satisfies $A \leq_p B$. The collection of all $\mathbf{NP}$-hard problems is denoted by the class \textbf{$\mathbf{NP}$-hard}.
\end{definition}

Importantly, an $\mathbf{NP}$-hard problem many not necessary lie in $\mathbf{NP}$. If it does, it is classified as $\mathbf{NP}$-complete. 

\begin{definition}[Class $\mathbf{NP}$-Complete] \label{def::class_np_complete}
  A decision problem $B$ is \textbf{$\mathbf{NP}$-complete} if $B \in \mathbf{NP}$, and $B$ is $\mathbf{NP}$-hard. The collection of all $\mathbf{NP}$-complete problems is denoted by the class \textbf{$\mathbf{NP}$-complete}.
\end{definition}

That is, one can establish that a problem is $\mathbf{NP}$-complete by showing that it belongs to $\mathbf{NP}$ and that a known $\mathbf{NP}$-complete problem can be reduced to it in polynomial time. 

The first known $\mathbf{NP}$-complete problem was established by the Cook-Levin theorem and is the Boolean satisfiability problem, or SAT. 

\begin{definition}[Boolean Satisfiability Problem] \label{def::SAT}
  The \textbf{Boolean satisfiability problem} (\textbf{SAT}) asks whether there exists an assignment of truth values to the variables of a given Boolean formula such that the formula evaluates to true. A Boolean formula is said to be \textbf{satisfiable} if such an assignment exists.
\end{definition}

Any Boolean formula can be transformed into an equisatisfiable formula typically in linear time using the \textbf{Tseytin transformation} by introducing additional variables. This transformation preserves satisfiability while ensuring only linear growth in the size of the resulting conjunctive normal form Boolean formula.  

\begin{definition}[Conjunctive Normal Form]
\label{def::CNF}
A Boolean formula is in \textbf{conjunctive normal form} (\textbf{CNF}) if it is expressed as a conjunction of clauses, where each clause is a disjunction of literals. That is, a CNF formula has the form
\[
C_1 \land C_2 \land \cdots \land C_m, \quad \text {where each clause $C_i$ is of the form} \quad
C_i = \ell_{i1} \lor \ell_{i2} \lor \cdots \lor \ell_{ik_i}
\]
and each $\ell_{ij}$ is either a Boolean variable or its negation denoted with $\lnot$.
\end{definition}

A further restriction is obtained by requiring each clause in a CNF formula to contain exactly three literals, which can be done using $3$-CNF transformation, to give the following problem.

\begin{definition}[3-SAT] \label{def::3SAT}
  The \textbf{3-SAT} problem asks whether there exists an assignment of truth values to the variables of a Boolean formula in conjunctive normal form such that every clause contains exactly three literals and the formula evaluates to true.
\end{definition}

3-SAT is a $\mathbf{NP}$-complete problem and will be used as the source problem for establishing the $\mathbf{NP}$-hardness of the graph square problem. 

\subsection{Graph Theory}

Objects, which are represented by vertices and edges representing relationships between them can be conveniently represented using a 

\begin{definition}[Graph] \label{def::graph}
  A \textbf{graph} $G$ is an ordered pair $(V,E)$, where $V$ is a set of vertices and $E$ is a set of edges between pairs of vertices in $V$.
\end{definition}

The number of vertices and edges in a graph provide basic measures of its
size.

\begin{definition}[Order and Size] \label{def::order_size}
  The \textbf{order} of a graph $G$, denoted by $|G|$, is the number of vertices in $G$, while the \textbf{size} of $G$ is the number of edges. Thus, if $V(G)=\{v_1,\ldots,v_n\}$ and $E(G)=\{e_1,\ldots,e_m\}$, then $|G|=n$ and $|E(G)|=m$.
\end{definition}

For a vertex $v$, the number of edges incident to it is its degree.

\begin{definition}[Degree] \label{def::degree}
  The \textbf{degree} of a vertex $v$ in a graph $G$, denoted by $\deg_G(v)$, is the number of edges incident to $v$. The minimum and maximum degrees of $G$ are denoted by
  \[
  \delta(G)=\min_{v\in V(G)}\deg_G(v) \quad \text{and} \quad \Delta(G)=\max_{v\in V(G)}\deg_G(v),
  \]
  respectively.
\end{definition}

The degree of a vertex can also be described through the vertices to which it is adjacent to.

\begin{definition}[Neighbourhood] \label{def::neighbourhood}
  For a vertex $v\in V(G)$, the \textbf{neighbourhood} of $v$ denoted by $N_G(v)$, is the set of vertices adjacent to $v$ in $G$. The \textbf{closed neighbourhood} of $v$ includes vertex $v$ and is denoted by 
  \[
  N_G[v]=N_G(v)\cup\{v\}.
  \]
\end{definition}

Connections between vertices can be described using walks, paths and cycles.

\begin{definition}[Walk] \label{def::walk}
  A \textbf{walk} from a vertex $v_i$ to a vertex $v_j$ in a graph $G$ is an alternating sequence of vertices and edges
  \[
  W=\langle v_i,e_1,v_1,e_2,\ldots,e_k,v_j\rangle,
  \]
  where each edge $e_r$ has endpoints given by the vertices immediately preceding and following it in the sequence. The number of edges in $W$ is called the \textbf{length} of the walk.
\end{definition}

\begin{definition}[Path] \label{def::path}
  A \textbf{path} is a walk in which no vertex is repeated.
\end{definition}

\begin{definition}[Cycle] \label{def::cycle}
  A \textbf{cycle} is a closed path in which the first and last vertices are the same and all other vertices are distinct.
\end{definition}

The length of a shortest cycle is an important structural parameter.

\begin{definition}[Girth] \label{def::girth}
  The \textbf{girth} of a graph $G$, denoted by $g(G)$, is the length of the shortest cycle in $G$. If $G$ contains no cycle, its girth is $\infty$.
\end{definition}

The length of a shortest path provides a natural measure of the distance between two vertices.

\begin{definition}[Distance] \label{def::distance}
  The \textbf{distance} between two vertices $u$ and $v$ on the graph $G$, denoted by $d_G(u,v)$, is the number of edges of the shortest path between vertices $u$ and $v$ in $G$. If no such path exists, $d_G(u,v) = \infty$. 
\end{definition}

\begin{definition}[Diameter] \label{def::diameter}
  The \textbf{diameter} of a graph $G$ is
  \[
  \operatorname{diam}(G) = \max_{u,v\in V(G)}d_G(u,v).
  \]
  For a disconnected graph, the diameter is $\infty$.
\end{definition}

If a graph has finite diameter it is connected. 

\begin{definition}[Connected Graph] \label{def::connected_graph}
  A graph $G$ is \textbf{connected} if there exists a path between every pair of vertices in $G$ Otherwise, $G$ is \textbf{disconnected}.
\end{definition}

A graph can be further categorized according to whether multiple edges between a vertex and itself are permitted, whether there are infinite number of vertices and edges, whether the edges represent an unordered or ordered relationship between their endpoints, and whether the vertices are labelled or unlabelled. 

\begin{definition}[Simple Graph] \label{def::simple_graph}
  A \textbf{simple graph} $G=(V,E)$ is a graph in which no two distinct edges connect the same pair of vertices and no edge connects a vertex to itself. 
\end{definition}

\begin{definition}[Finite Graph] \label{def::finite_graph}
  A \textbf{finite graph} is a graph $G=(V,E)$ for which both $V$ and $E$ are finite sets. A graph that is not finite is called an \textbf{infinite graph}.
\end{definition}

\begin{definition}[Directed Graph] \label{def::directed_graph}
  A \textbf{directed graph} $G=(V,E)$ is a graph in which each edge $e\in E$ is an ordered pair of distinct vertices in $V$. Thus, $(u,v)$ represents an edge directed from $u$ to $v$, where 
  $(u,v)$ may not necessarily be equal to $(v,u)$.

  An \textbf{undirected graph} $G=(V,E)$ is a graph in which each edge $e\in E$ is an unordered pair of distinct vertices in $V$. Thus, $\{u,v\}=\{v,u\}$ for every edge between vertices $u$ and $v$.
\end{definition}

\begin{definition}[Labelled Graph] \label{def::labelled_graph}
  A \textbf{labelled graph} is a graph $G=(V,E)$ together with a labelling function $\ell:V\rightarrow L$, where $L$ is a set of labels. A graph is \textbf{unlabelled} when no such vertex labels are specified. 
\end{definition}

In this thesis, we exclusively study finite, simple, undirected, unlabelled graphs. However, the constructions and algorithms may use additional structure, including labels or multiple edges, which must be analysed and restricted to their corresponding simple, unlabelled counterparts.

In particular, two graphs may have different vertex sets while nevertheless having the same underlying structure. This motivates the following notion of isomorphism.

\begin{definition}[Graph Isomorphism] \label{def::graph_isomorphism}
  Let $G$ and $H$ be graphs. An \textbf{isomorphism} from $G$ to $H$ is a bijection
  \[
  f:V(G)\rightarrow V(H) \quad \text{such that} \quad uv\in E(G) \text{ if and only if } f(u)f(v)\in E(H).
  \]
  We say that $G$ is \textbf{isomorphic} to $H$, written
  $G\cong H$, if there exists an isomorphism from $G$ to $H$.
\end{definition}

The isomorphism relation is an equivalence relation on the set of graphs, and an \textbf{isomorphism class} is an equivalence class of graphs under this relation. Thus, graphs within the same isomorphism class have the same structure up to a relabelling of their vertices.

We will also consider graphs obtained by restricting the vertices and edges of another graph.

\begin{definition}[Subgraph] \label{def::subgraph}
  A graph $H=(V(H),E(H))$ is a \textbf{subgraph} of a graph $G=(V(G),E(G))$ if
  \[
  V(H)\subseteq V(G) \quad \text{and} \quad E(H)\subseteq E(G).
  \]
  For $S\subseteq V(G)$, the \textbf{induced subgraph} of $G$ on $S$, denoted by $G[S]$, is the graph with vertex set $S$ and edge set
  \[
  E(G[S])=\{uv\in E(G):u,v\in S\}.
  \]
\end{definition}

One of the most important types of graphs is the complete graph, and its subgraph counterpart. 

\begin{definition}[Complete Graph] \label{def::complete_graph}
  A graph on $n$ vertices is \textbf{complete} if every pair of distinct vertices is adjacent. The complete graph on $n$ vertices is denoted by $K_n$.
\end{definition}

\begin{definition}[Clique] \label{def::clique}
  A \textbf{clique} of a graph $G$ is a subset $S\subseteq V(G)$ such that the induced subgraph $G[S]$ is complete. The \textbf{clique number} of $G$, denoted by $\omega(G)$, is the size of a largest clique in $G$.
\end{definition}

The graph structures above can be represented algebraically using matrices.

\begin{definition}[Adjacency Matrix] \label{def::adjacency_matrix}
  The \textbf{adjacency matrix} of graph $H$ is denoted by $A_H \in \{0,1\}^{n \times n}$ where
  \[
  (A_H)_{ij} =
  \begin{cases}
  1 ,& \text{if } ij \in E_H, \\
  0 ,& \text{otherwise},
  \end{cases}
  \]
\end{definition}

The degrees of the vertices can similarly be represented by a diagonal matrix.

\begin{definition}[Degree Matrix] \label{def::degree_matrix}
  The \textbf{degree matrix} of graph $H$ is denoted by $D_H \in \mathbb{R}^{n \times n}$ where
  \[
  (D_H)_{ij} =
  \begin{cases}
  \deg_H(i) ,& \text{if } i = j, \\
  0 ,& \text{otherwise}.
  \end{cases}
  \]
\end{definition}

\begin{definition}[Indicator Function] \label{def::indicator_function}
  Let $\mathbbm{1}_{\geq 1} : \mathbb{R}^{n \times n} \to \{0,1\}^{n \times n}$ denote the entrywise \textbf{indicator function}, defined by
  \[
  \mathbbm{1}_{\geq 1}(M)_{ij} =
  \begin{cases}
  1 ,& \text{if } M_{ij} \geq 1, \\
  0 ,& \text{otherwise}.
  \end{cases}
  \]
\end{definition}

We now introduce the graph-theoretic objects central to this thesis.

\begin{definition}[Graph Root] \label{def::graph_root}
  Let the \textbf{graph root} $H = (V, E_H)$ be a finite, simple, undirected graph, where $V$ is the vertex set with $|V| = n$, and $E_H \subseteq \{\{u,v\} \mid u,v \in V,\; u \neq v\}$ is the edge set. 
\end{definition}

\begin{definition}[Square of a Graph] \label{def::square_of_a_graph}
  The \textbf{square of a graph} $H$, denoted by $H^2 = (V, E_{H^2})$ is the graph on the same vertex set with edge set
  \begin{equation} \label{eq::fund_def_square}
    E_{H^2} = \{\, uv \mid u \neq v,\; 1 \leq d_H(u,v) \leq 2 \,\}.
  \end{equation}
  That is, two distinct vertices are adjacent in $H^2$ if and only if they are connected by a path of length one or two in $H$. This is the standard definition of the square of a graph. 
\end{definition}

\begin{definition}[Graph Square] \label{def::graph_square}
    The \textbf{graph square} of $H$ is the undirected graph defined on the same vertex set $G = (V, E_G)$. Define the adjacency matrix of $G$ using the adjacency and degree matrices of $H$
    \begin{equation} \label{eq::fund_adj_eq_undirected}
      A_G = \mathbbm{1}_{\geq 1}\!\big((A_H)^2 - D_H + A_H\big).
    \end{equation}
\end{definition} 

\begin{definition} \label{def::pendant}
  A pendant subgraph is the induced subgraph on three vertices $s,u,v$ where $s$ is a leaf with unique neighbour $u$, and $u$ is a stem of degree $2$ with neighbours $s$ and $v$, where $v$ connects the subgraph to the remainder of the tree.
\end{definition}

\begin{definition} \label{def::leaf_clique}
  A leaf clique subgraph is the induced subgraph on four vertices $s_1,s_2,u,v$ where $s_1,s_2$ are leaves with unique neighbour $u$, and $u$ is an internal vertex of degree $\geq 3$ where $\{s_1,s_2, v\} \subseteq N(u)$, where $v$ connects the subgraph to the remainder of the tree.
\end{definition}

\subsection{Mathematical Optimization}

Mathematical optimization studies the problem of finding the best solution from all feasible solutions which are defined by a collection of constraints. An optimization problem usually consists of decision variables, an objective function to be maximized or minimized, and a set of constraints restricting the feasible values of the variables.

\begin{definition}[Integer Program] \label{def::integer_program}
  An \textbf{integer program} ($LP$) is an optimization problem of the form
  \[
  \begin{aligned}
    \text{max/min}\quad & c^\top x\\
    \text{subject to}\quad & Ax\leq b,\\
    & x\in\mathbb{Z}^n,
  \end{aligned}
  \]
  where $x\in\mathbb{Z}^n$ is the vector of decision variables, $c\in\mathbb{R}^n$ is the objective coefficient vector, $A\in\mathbb{R}^{m\times n}$ is the constraint matrix, and $b\in\mathbb{R}^m$ is the constraint vector.
\end{definition}

A linear relaxation is obtained by removing the integrality requirements from an integer program while retaining its linear objective function and constraints.

\begin{definition}[Linear Relaxation] \label{def::linear_relaxation}
  Let $IP$ be an integer program. The \textbf{linear relaxation} of $IP$ is the linear program obtained by removing the requirement that its variables take integer values.
\end{definition}

\begin{definition}[Linear Program] \label{def::linear_program}
  A \textbf{linear program} ($LP$) is an optimization problem of the form
  \[
  \begin{aligned}
  \text{max/min}\quad & c^\top x\\
  \text{subject to}\quad & Ax\leq b,\\
  & x\in\mathbb{R}^n,
  \end{aligned}
  \]
  where $x\in\mathbb{R}^n$ is the vector of decision variables, $c\in\mathbb{R}^n$ is the objective coefficient vector, $A\in\mathbb{R}^{m\times n}$ is the constraint matrix, and $b\in\mathbb{R}^m$ is the constraint vector.
\end{definition}

\begin{definition}[Feasible Solution] \label{def::feasible_solution}
  A \textbf{feasible solution} to an optimization problem is an assignment of values to its decision variables that satisfies all of its constraints. The set of all feasible solutions is called the \textbf{feasible set} and is denoted by $\mathcal{F}$. Geometrically, $\mathcal{F}$ is the subset of the decision-variable space satisfying all of the constraints and is
  referred to as the \textbf{feasible region}.
\end{definition}

Among the feasible solutions, an optimal solution is one that achieves the best value of the objective function.

\begin{definition}[Optimal Solution] \label{def::optimal_solution}
  An \textbf{optimal solution} is a feasible solution that maximizes or minimizes the objective function, depending on the optimization problem. The corresponding value of the objective function is called the \textbf{optimal value} and is denoted by $\operatorname{OPT}$.
\end{definition}

When an integer program is relaxed to a linear program, every feasible integer solution remains feasible for the relaxation. Consequently, if $\mathcal{F}_{IP}$ and $\mathcal{F}_{LP}$ denote the feasible sets of the integer program and its linear relaxation respectively, then
\[
\mathcal{F}_{IP} \subseteq \mathcal{F}_{LP}.
\]
Geometrically, $\mathcal{F}_{IP}$ is represented by the feasible integer points in the decision-variable space, whereas $\mathcal{F}_{LP}$ is the polyhedron defined by the relaxed constraints and may contain additional points.

\input{subfiles/LinearRelaxationSetGeometry.tex}

For a maximization problem, this set inclusion implies $\operatorname{OPT}_{IP} \leq \operatorname{OPT}_{LP}$, so the linear relaxation provides an upper bound on the optimal value of the integer program. For a minimization problem, $\operatorname{OPT}_{LP} \leq \operatorname{OPT}_{IP}$, so the linear relaxation provides a lower bound.

\begin{definition}[Integer Hull] \label{def::integer_hull}
  Let $\mathcal{F}_{IP}$ denote the feasible set of an integer program. The \textbf{integer hull} is the convex hull of the feasible integer solutions, denoted by $\operatorname{conv}(\mathcal{F}_{IP})$. That is, the integer hull is the set of all convex combinations of points in $\mathcal{F}_{IP}$.
\end{definition}

Since the feasible region of a linear program is convex, the integer hull is contained in the feasible region of its linear relaxation. Hence,
\[
\mathcal{F}_{IP} \subseteq \operatorname{conv}(\mathcal{F}_{IP}) \subseteq \mathcal{F}_{LP}.
\]
The integer hull is the smallest convex set containing all feasible integer solutions. Thus, geometrically, the gap between the integer hull and the LP feasible region represents the additional solutions admitted by the relaxation. If
\[
\operatorname{conv}(\mathcal{F}_{IP}) = \mathcal{F}_{LP},
\]
then the linear relaxation coincides with the integer hull and is therefore an exact convex description of the feasible integer solutions.

\section{NP-Completeness Proof} \label{sec::np_completeness_proof}

We now establish the computational complexity of the graph square problem as was established by \citeauthor{motwani_sudan_1994_roots} in their paper \cite{motwani_sudan_1994_roots}. The decision version of the problem asks whether a given graph admits a graph root whose square is the given graph.

\begin{definition}[SQUARE] \label{def::square_problem}
\leavevmode

\textbf{Instance:} A finite, simple, undirected graph $G=(V,E)$.
\medskip

\textbf{Question:} Does there exist a finite, simple, undirected graph $H$ such that
\[
G = H^2?
\]
\end{definition}

To show that Definition~\ref{def::square_problem} is $\mathbf{NP}$-complete, it is necessary to show that it is in $\mathbf{NP}$ and that it is $\mathbf{NP}$-hard by reducing not-all-equal SAT (NAESAT) to the problem. 

Given a candidate square root $H$, one can verify in polynomial time whether $G = H^2$ by computing the distances between pairs of vertices in $H$, or equivalently by constructing the square $H^2$ and comparing its edge set with that of $G$. Hence, $H$ provides a polynomially verifiable certificate for a \textbf{Yes}-instance of SQUARE and therefore
\[
\text{SQUARE}\in\mathbf{NP}.
\]

\section{Polynomial Time Algorithm} \label{sec::square_of_a_tree}

\citeauthor{ross_1960_square} give a necessary and sufficient characterization of graphs that are squares of trees, together with an algorithm for constructing the corresponding tree square root. The characterization is based on the maximal cliques of the square and the way in which these cliques intersect. We first establish the structural properties of the square of a tree that underlie the characterization, before describing the root finding algorithm.

\begin{theorem}[Structural Characterization of Squares of Trees] \label{theoremm::structural_characterization_trees}

Let $G$ be a finite, simple, undirected graph. Then $G=T^2$ for some tree $T$ if and only if either $G=K_p$ is complete, or the maximal cliques $C_1, \ldots, C_n$ of $G$ satisfy the following properties:
\begin{enumerate}[label=(\roman*)]
  \item\label{characterization:1} Every vertex of $G$ forms a clique with its neighbours and $G$ is connected 
  \item\label{characterization:2} If two cliques intersect at only one point $v$ then there is a third clique with which they share $v$ and exactly one other point 
  \item\label{characterization:3} A clique $C(v)$ in $G$ corresponding to $v$ in $T$ contains exactly as many points in multiple cliques as the number of cliques which include $v$
  \item\label{characterization:4} Every pair of cliques intersect at at most two points 
  \item\label{characterization:5} The number of pairs of cliques that meet at two points is one less than the number of cliques 
\end{enumerate}
\end{theorem}

To show this, we require the following lemmas 

\begin{lemma}\label{lemma::1}
  $G$ is complete if and only if $T$ has depth one. 
\end{lemma}
\begin{proof}
  Suppose that $T$ has a vertex $v$ that is adjacent to every other vertex. Then every pair of vertices in $T$ is at distance at most two, since any two vertices are either adjacent or have $v$ as a common neighbour. Hence $G=T^2$ is complete.

  Conversely, suppose that $G=T^2$ is complete. Then every pair of vertices in $T$ has distance at most two, so $\operatorname{diam}(T)\leq 2$. Since $T$ is a tree, this implies that there is a vertex $v$ adjacent to every other vertex. Thus, choosing $v$ as the root gives a rooted tree $T$ of depth one.
\end{proof}

\begin{lemma} \label{lemma::2}
  Every vertex of $G$ forms a clique with its neighbours and $G$ is connected
\end{lemma}
\begin{proof}
  Let $v\in V(T)$. Every pair of vertices in the closed neighbourhood $N_T[v]$ has distance at most two in $T$. Hence $N_T[v]$ forms a
  clique in $G=T^2$. Every edge of $T$ is also an edge of $G$, so $T$ is a spanning subgraph of $G$. Since $T$ is connected, this implies $G$ is also connected.
\end{proof}

\begin{lemma}\label{lemma::3}
  Every maximal clique of $G$ corresponds to a closed neighbourhood of a non-leaf vertex and every closed neighbourhood of a non-leaf vertex in $T$ form a clique in $G$
\end{lemma}
\begin{proof}
  Consider a non-leaf vertex $v\in V(T)$. The vertices in $N_T(v)$ are pairwise at distance two in $T$, and are therefore pairwise adjacent in $G=T^2$. Hence $C(v)=N_T[v]$ forms a clique in $G$. This clique is maximal since every vertex in $C(v)$ is either $v$ itself or a neighbour of $v$ in $T$, and any vertex outside $N_T[v]$ cannot be added while preserving adjacency to all vertices of $C(v)$.

  Conversely, let $C$ be a maximal clique of $G$. A set of leaves in $T$ cannot form a clique in $G$ unless the leaves have a common neighbour. Hence there exists a non-leaf vertex $v\in V(T)$ such that all vertices of $C$ are contained in $N_T[v]$. Since $N_T[v]$ forms a clique in $G$ and $C$ is maximal, it follows that $C=N_T[v]=C(v)$. Thus every maximal clique of $G$ corresponds to the closed neighbourhood of a non-leaf vertex of $T$.
\end{proof}

\begin{lemma}\label{lemma::4}
  If $G$ has more than one maximal clique, then vertex $v$ is in exactly one maximal clique in $G$ if and only if $v$ is a leaf in $T$
\end{lemma}
\begin{proof}
  Suppose first that $v$ is a leaf in $T$, with unique neighbour $w$. By Lemma~\ref{lemma::3}, every maximal clique of $G$ corresponds to the closed neighbourhood of a non-leaf vertex in $T$. Since $v$ has only one neighbour, the only such closed neighbourhood containing $v$ is $N_T[w]$. Hence $v$ belongs to exactly one maximal clique.

  Conversely, suppose that $v$ is not a leaf. Then $v$ has at least two neighbours in $T$. By Lemma~\ref{lemma::3}, $N_T[v]$ is a maximal clique in $G$. Since $G$ has more than one maximal clique, the structure of $T$ gives another non-leaf vertex whose closed neighbourhood contains $v$. Hence $v$ belongs to more than one maximal clique.
\end{proof}

\begin{lemma}\label{lemma::5}
  Two non-leaves of $T$ are adjacent in $T$ if and only if their neighbourhoods are cliques of $G$ that intersect in exactly two points
\end{lemma}
\begin{proof}
  Suppose that the maximal cliques corresponding to two non-leaf vertices $v,w\in V(T)$ intersect in exactly two vertices. If $v$ and $w$ were not adjacent in $T$, then they would be at distance two and would have a common neighbour $u$ in $T$. Hence $u$, together with $v$ and $w$, would belong to both maximal cliques, giving an intersection of at least three vertices, a contradiction. Therefore $v$ and $w$ are adjacent in $T$.

  Conversely, suppose that $v$ and $w$ are adjacent non-leaf vertices of $T$. Then both $v$ and $w$ belong to the closed neighbourhood of each vertex, so they belong to both corresponding maximal cliques. Suppose that there is a third vertex $u$ in their intersection. Then $u$ is adjacent in $T$ to both $v$ and $w$. Together with the edge $vw$, this creates a cycle in $T$, contradicting that $T$ is a tree. Hence the two maximal cliques intersect in exactly $v$ and $w$, and therefore in exactly two vertices.
\end{proof}

\begin{lemma}\label{lemma::6}
  $G$ is a connected graph where the removal of any edge does not result in a disconnected graph
\end{lemma}
\begin{proof}
  By construction, there exists an alternative path between every pair of vertices $v,w\in V(G)$. Consider an edge $vw\in E(G)$. If $vw\in E(T)$, then, since $G$ is not complete, at least one of $v$ and $w$ is a non-leaf vertex. Without loss of generality, let $v$ be non-leaf and let $u\in N_T(v)$ with $u\neq w$. Then $v$ and $w$ are both adjacent to $u$ in $G$, since $u$ and $w$ are at distance two in $T$.Then $vu,uw\in E(G)$, so $v-u-w$ remains a path after $vw$ is removed. Hence removing $vw$ does not disconnect $G$.

  If $vw\notin E(T)$, then $vw\in E(G)$ because $v$ and $w$ are at distance two in $T$, so there already exists a path $v-u-w$ in $T$ and therefore in $G$. Thus, in either case, removing $vw$ does not disconnect $G$.
\end{proof}

Combining this gives the following proof of Theorem~\eqref{theorem::structural_characterization_trees}
\begin{proof}
  Suppose first that $G=T^2$ for some tree $T$. If $G$ is complete,
  then Lemma~\ref{lemma::1} applies. Otherwise, by
  Lemma~\ref{lemma::2}, $G$ is connected and every vertex together
  with its neighbours in $T$ forms a clique in $G$, giving
  \hyperref[characterization:1]{(i)}. By
  Lemma~\ref{lemma::3}, the maximal cliques of $G$ correspond to the
  closed neighbourhoods of the non-leaf vertices of $T$. The
  structure of these neighbourhoods gives
  \hyperref[characterization:2]{(ii)} and
  \hyperref[characterization:3]{(iii)}. By
  Lemma~\ref{lemma::5}, two such cliques intersect in exactly two
  vertices precisely when their corresponding non-leaf vertices are
  adjacent in $T$. Hence any two maximal cliques intersect in at most
  two vertices, giving \hyperref[characterization:4]{(iv)}. Moreover,
  the pairs of maximal cliques that intersect in two vertices
  correspond exactly to the edges between the non-leaf vertices of
  $T$. Since these vertices form a tree after the leaf vertices are
  removed, the number of such pairs is one less than the number of
  maximal cliques, giving \hyperref[characterization:5]{(v)}.
  
  Conversely, suppose that $G$ is not complete and that its maximal
  cliques $C_1,\ldots,C_n$ satisfy \hyperref[characterization:1]{(i)}
  --\hyperref[characterization:5]{(v)}. By
  \hyperref[characterization:3]{(iii)}, the maximal cliques can be
  associated with their multicliqual vertices. Construct a graph
  $T$ whose vertices initially consist of these multicliqual
  vertices. For every pair of maximal cliques that intersect in two
  vertices, join the corresponding multicliqual vertices by an edge.
  By \hyperref[characterization:4]{(iv)} and
  \hyperref[characterization:5]{(v)}, these edges form a tree on the
  multicliqual vertices.
\end{proof}

Theorem~\eqref{theorem::structural_characterization_trees} gives the following algorithm. Given an inputted tree square, by identifying all maximal cliques, finding all points which are in multiple cliques and those in only one clique, and constructing the tree  $T$ by appropriately connecting multicliqual points together as internal vertices and unicliqual points as the tree leaves. 

\begin{algorithm} \label{algo::ross_harary_tree}
\begin{algorithmic}[1]
\State \textbf{Input:} A graph $G$ where $G = T^2$
\State \textbf{Output:} A tree $T$
\vspace{0.5em}

\Statex \textbf{Step 1}
\If{$G = K_p$ is complete}
    \State \textbf{Return} tree $T$ with depth $1$ where root can be any vertex
\Else
    \State \textbf{Continue}

\vspace{0.5em}

\Statex \textbf{Step 2}
\State Identify all maximal cliques $C_1, \dots, C_n$ of $G$ using an algorithm such as Bron-Kerbosch where $n > 1$

\vspace{0.5em}

\Statex \textbf{Step 3}
\State Let $b_1, \dots, b_n$ be multicliqual points corresponding to $C_1, \dots, C_n$ formed from 
\hyperref[characterization:3]{characterization (iii)} 
\State Construct a graph $S$ with vertex set $\{b_1, \dots, b_n\}$
\For{each pair $(C_i, C_j)$ satisfying $|C_i \cap C_j| = 2$  }
    \State Add edge between $b_i$ and $b_j$ in $S$

\end{algorithmic}

\begin{lemma} \label{lemma::G_equal_to_H^2}
  The graph $G$ defined by Definition~\eqref{def::graph_square} is equivalent to the graph square $H^2$ defined in Definition~\eqref{def::square_of_a_graph} 
  \begin{equation} \label{eq::fund_def_square_expanded}
    ij \in E_{H^2} \text{ if and only if } 1 \leq d_H(i,j) \leq 2. 
  \end{equation}
\end{lemma}
\begin{proof} 
  For $i \neq j$, since $D_H$ is diagonal, have $(D_H)_{ij} = 0$ and hence
  \[
  \big((A_H)^2 - D_H + A_H\big)_{ij} = (A_H)^2_{ij} + (A_H)_{ij}.
  \]

  Suppose $ij \in E_G$ such that $(A_H)^2_{ij} + (A_H)_{ij} \geq 1$. This implies that at least on of $(A_H)_{ij} = 1$ or $(A_H)^2_{ij} \geq 1$ must be true. If $(A_H)_{ij} = 1$, then $d_H(i,j) = 1$.  If $(A_H)^2_{ij} \geq 1$, then there exists a vertex $k$ such that $ik, kj \in E_H$, and hence $d_H(i,j) \leq 2$. Therefore $1 \leq d_H(i,j) \leq 2$, and thus $ij \in E_{H^2}$.

  Suppose $ij \in E_{H^2}$ such that $1 \leq d_H(i,j) \leq 2$. $D_H$ is diagonal such that $(D_H)_{ij} = 0$. If $d_H(i,j) = 1$, then $(A_H)_{ij} = 1$. If $d_H(i,j) = 2$, then there exists a vertex $k$ such that $ik, kj \in E_H$, and hence $(A_H)^2_{ij} \geq 1$. In either case, $(A_H)^2_{ij} + (A_H)_{ij} \geq 1$, so $(A_G)_{ij} = 1$, and hence $ij \in E_G$.

  For $i = j$, since all graphs are simple, have $(E_{\cdot})_{ii} = 0$, $(A_{\cdot})_{ii} = 0$ and hence
  \[
  \big((A_H)^2 - D_H + A_H\big)_{ii} = (A_H)^2_{ii} - (D_H)_{ii}.
  \]
  $(A_H)^2_{ii} - (D_H)_{ii} = 0$ is always true since the degree matrix of $H$ always has diagonal values $\displaystyle (D_H)_{ii} = \sum_k x_{ik}$ and each edge from vertex $i$ to its neighbour in $H$ will always create a loop to itself in the square such that $\displaystyle (A_H)^2_{ii} = 
  \sum_{k = 1} x_{ik}x_{ki} = \sum_{k = 1} x_{ik}^2$ by the symmetry of adjacency matrix $A_H$. Since $x_{ik} \in \{0, 1\}$, the square of the boolean is identical to the boolean $x_ik$ such that $\displaystyle (A_H)^2_{ii} = \sum_k x_{ik} = (D_H)_{ii}$ and $(A_G)_{ii} = \mathbbm{1}_{\geq 1}\big((A_H)^2 - D_H + A_H\big)$ as required. 

  Combining both gives that $E_G = E_{H^2}$, and so $G = H^2$.  
\end{proof}

The formulation of the adjacency matrix of the graph square in Equation~\eqref{eq::fund_adj_eq_undirected} is very powerful. However, the presence of the indicator function introduces a nonlinearity that prevents the problem from being expressed as a purely quadratic form, thereby limiting the direct applicability of existing results from the quadratic optimization literature.

\begin{lemma} \label{lemma::no_indicator_girth_5}
  If there are no $K_3$ triangle subgraphs or any $C_4$ square subgraphs in the graph root such that $H$ has girth of length $5$, then Equation~\eqref{eq::fund_adj_eq_undirected} can be simplified to become 
  \begin{equation} \label{eq::fund_adj_eq_undirected_no_indicator}
    A_G = \big((A_H)^2 - D_H + A_H\big).
  \end{equation}
\end{lemma}
\begin{proof}
  Since the graph root has girth $5$ there are no cycles of length $3$ or $4$ in $H$. Thus for every pair of vertices $i \neq j \in V$ there is either no cycle that connects $i,j$ or there is a cycle of at least length $5$ between them. In all cases $(D_H)_{ij} = 0$. If there is no cycle, then there is at most one path between $i,j$
  \begin{enumerate}[label=\roman*)]
    \item If the path is of length $1$, then $(A_H)_{ij} = 1, (A_H)^2_{ij} = 0 \implies (A_G)_{ij} = 0 - 0 + 1 = 1$.
    \item If the path is of length $2$, then $(A_H)_{ij} = 0, (A_H)^2_{ij} = 1 \implies (A_G)_{ij} = 1 - 0 - 0 = 1$.
    \item If the path is of length $\geq 3$ or a path does not exist, then $(A_H)_{ij} = 0, (A_H)^2_{ij} = 0 \implies (A_G)_{ij} = 0$.
  \end{enumerate}
  If there is a cycle of length $\geq 5$ between $i,j$ such that there are two paths between $i,j$
  \begin{enumerate}[label=\roman*)]
    \item If one path is of length $1$, then the other is of length $\geq 4$ and hence $(A_H)_{ij} = 1, (A_H)^2_{ij} = 0 \implies (A_G)_{ij} = 0 - 0 + 1 = 1$.
    \item If one path is of length $2$, then the other is of length $\geq 3$ and hence $(A_H)_{ij} = 0, (A_H)^2_{ij} = 1 \implies (A_G)_{ij} = 1 - 0 - 0 = 1$.
    \item If the paths are both of length $\geq 3$,  then $(A_H)_{ij} = 0, (A_H)^2_{ij} = 0 \implies (A_G)_{ij} = 0$. 
  \end{enumerate}
  If $i = j$, then $(A_H)_{ii} = 0$, $(D_H)_{ii} = \deg_H(i)$, and $(A_H)^2_{ii} = \deg_H(i)$. Thus,
  \[
  (A_H)^2_{ii} - (D_H)_{ii} + (A_H)_{ii} = \deg_H(i) - \deg_H(i) + 0 = 0 = (A_G)_{ii}.
  \]
\end{proof}

\section{Symbolic Groups} \label{sec::symbolic_groups}

Lemma~\ref{lemma::two_edges_integer_sum} and its linear relaxation equivalent Lemma~\ref{lemma::two_edges_linear_sum} give extremely strong structure into how the linear program operates. Using the maximization objective function Lemma~\ref{lemma::two_edges_linear_sum}, any two edges $ij$, $jk$ which exist in $G$ but $ki$, can be assigned the weights $a$, $b$ respectively where $x_{ij} = a$, $x_{jk} = b$ and $a + b \leq 1$. 

Under certain conditions, the relationship can hold with equality $a + b = 1$ which therefore gives a methodology for tackling scenarios where the maximal fractional objective function is greater than the optimal integer objective function corresponding to a valid square root. By continuously iterating Lemma~\ref{lemma::two_edges_linear_sum} can eventually categorize and formulate equations for many of the weights on the various edges.
